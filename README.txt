チャッピーDX オンライン版

このフォルダをNode.js対応のWebサービスへ配置すると、同じURLを友達へ送って遊べます。

必要:
- Node.js 18以上

起動:
1. npm install
2. npm start
3. ブラウザで http://localhost:3000

公開時:
- HTTPSで公開してください。
- ゲーム側は https の場合、自動的に wss://公開ホスト/ws を使います。
- 友達には公開URLだけ送ればOKです。

オンライン:
- 会社運営・野球・サッカーの3モード対応
- ルームコード方式
- WebSocketで状態同期
- ホスト/ゲスト
- 接続人数表示

注意:
この環境から外部サービスへ恒久的な公開URLを発行することはできません。公開サービスへ配置する必要があります。
